# Unity Scripts Repository

Bu repository, Unity ile geliştirilmiş oyun için kullanılan scriptleri içerir.

## İçerik
- Unity oyun geliştirme sürecinde kullanılan ana scriptler.
- Scriptlerin işlevleri, optimizasyon yaklaşımları ve hata ayıklama yöntemleri hakkında bilgiler yer almaktadır.

## Notlar
- Scriptler düzenli olarak güncellenmekte ve iyileştirilmektedir.
- Detaylı dokümantasyon repo içerisinde bulunabilir.
